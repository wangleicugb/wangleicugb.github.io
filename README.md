# Sustainable and Resilient Geotechnical Infrastructure Laboratory

Static GitHub Pages version of the Lei Wang UC geotechnical engineering laboratory website.

## Files

- `index.html` — UC-styled homepage with hero, about, research, open position, news, and contact sections.
- `publications.html` — publications page with journal and conference lists.
- `position.html` — graduate assistantship/open position page copied into the static site.
- `assets/css/style.css` — UC-inspired red/black/white responsive styling.
- `assets/images/` — downloaded images/icons from the current WordPress site.

## Deploy on GitHub Pages

1. Create or open the GitHub repository.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Set source to **Deploy from a branch**.
5. Choose branch `main` and folder `/root`.
6. Save; GitHub will publish the site after a short build.

## UC styling notes

This draft uses UC primary colors: red `#e00122`, black `#000000`, white `#ffffff`, plus accessible greys. It avoids using an official UC logo file so the site remains simple and safe for GitHub Pages unless the department provides approved logo assets.
